About

Indie craft,
zero compromise.

PixelNova Studios is a solo-founded indie game studio focused on arcade-perfect web games.

Mission

To prove that a single developer with a canvas and pure JS can produce an experience that rivals studio-budget mobile games — in feel, not budget.

Every game we ship must be playable in 30 seconds and still rewarding at 30 hours.

Principles

  • Zero friction — instant play, no login, no install
  • Language-free gameplay UI (icons + numerals only)
  • No image assets — all art drawn in canvas code
  • 60 fps or we don't ship
  • Honest monetisation: caps, opt-ins, no dark patterns
  • File size under 3 MB, load under 2 seconds
